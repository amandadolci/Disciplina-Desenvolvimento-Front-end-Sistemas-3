## Exercício 1: Buscar Usuário pelo ID

Crie um componente React que tenha:

- Um campo de entrada (input) onde o usuário pode digitar um ID.
- Um botão "Buscar", que ao ser clicado, faz uma requisição GET para buscar um usuário na API https://jsonplaceholder.typicode.com/users/{id}.
- Uma exibição dos dados do usuário na tela (nome e email).
- Se o usuário não for encontrado, exibir uma mensagem de erro.

## Exercício 2: Criar um Novo Usuário

Crie um formulário que permita ao usuário cadastrar um novo usuário na API https://jsonplaceholder.typicode.com/users via POST. O formulário deve conter:

- Um campo de entrada (input) para o nome do usuário.
- Um campo de entrada (input) para o e-mail do usuário.
- Um botão "Cadastrar", que ao ser clicado, envia os dados para a API.
- Uma mensagem de sucesso ou erro após o envio.
